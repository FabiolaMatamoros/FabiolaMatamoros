## Projects

** Auto Death Counter for OBS** — *JavaScript · OBS WebSocket · Canvas*
A stream overlay that counts deaths in *Phantom Blade Zero* on its own. It requests in memory frames of the game from OBS and uses template matching to detect the death screen, the boss health bar, and the boss-defeated screen. It keeps a total count plus a per-boss count that resets when the boss goes down, with Stream Deck buttons for manual corrections.

** KireiApp** — *Ruby on Rails 8 · Inertia · React · PostgreSQL · Claude API · WhatsApp Cloud API · Paddle*
A multi-tenant SaaS, live at [kireicr.app](https://kireicr.app), that lets business owners manage their schedules and appointments in one place. Owners see every booking with per-staff filters, while employees only see the appointments assigned to them, with role-based access handled through Devise and Pundit. The app is bilingual (Spanish/English) and runs on recurring subscriptions billed through Paddle. I'm currently building an AI booking assistant powered by Claude that connects to each business's own WhatsApp number through Meta's Embedded Signup, checks availability against Google Calendar, books clients directly into the app, and remembers returning clients and their usual services.
Live at [kireicr.app](https://kireicr.app) · *private repo*
